# Student Marks Management System (C++)

A C++ program that applies Object-Oriented Programming (OOP) concepts to manage student marks.  
The program uses constructors, friend functions, and class methods to calculate the total marks of students and determine the top-performing student.

---

## 📌 Features
- Uses default and parameterized constructors
- Accepts student data (name and mark)
- Calculates the total marks of multiple students
- Determines the student with the highest mark
- Handles equal marks cases

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Classes & Objects
- Constructors (Default & Parameterized)
- Friend Functions
- Conditional Statements
- Encapsulation (Basic)
- Console Input / Output

---

## 🛠️ Technologies
- Language: C++
- Compiler: Any standard C++ compiler (g++, MSVC, etc.)

---

## ▶️ How to Run
1. Clone the repository
2. Compile the code using a C++ compiler  
   ```bash
   g++ main.cpp -o student_marks
